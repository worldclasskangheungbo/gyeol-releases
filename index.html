정리

버튼 하나로,
몇 기가가 돌아옵니다.

캐시·로그·휴지통·중복 파일·앱 잔여물까지. 모든 정리는 사용자 영역만 건드리고, 삭제 대신 휴지통으로 이동해 언제든 되돌릴 수 있습니다.

⚡ 부스트

사용자 캐시 + 로그 + 휴지통을 한 번에. 일·주·월 단위 백그라운드 자동 정리 예약도 지원합니다.

지금 정리하기

딥 클린

브라우저·개발 도구·Xcode·임시·진단 캐시를 카테고리별로 심층 정리. 오래된 다운로드도 찾아냅니다.

중복 파일

SHA-256 해시로 내용이 똑같은 파일을 찾아 한 개만 남기고 일괄 정리합니다.

앱 정리

앱을 지워도 남는 잔여물(설정·캐시·지원 파일)까지 함께 제거하는 삭제 도우미.

대용량 파일

100MB 이상 대용량 파일을 타입별로 스캔 — Finder에서 열거나 휴지통으로.

저장공간 탐색

폴더별 용량을 트리맵으로 시각화하고 드릴다운 — 어디가 무거운지 한눈에.

폴더 정리 + 압축

다운로드·데스크탑을 이미지/문서/영상별 자동 분류. ZIP·TAR.GZ 압축·해제(암호 지원)까지.

매일 쓰는 도구

청소 앱인 줄 알았는데,
매일 열게 됩니다.

스크린샷 OCR, 클립보드 히스토리, 창 스냅, 맥 응급처치 — 하루에도 몇 번씩 쓰는 도구들을 담았습니다.

스크린샷 + OCR

전체·영역·창 캡처(PNG·JPG·PDF)에 더해, 화면 속 글자를 온디바이스 Vision으로 추출합니다(한·영). 화면 위에 펜·화살표·도형을 그리는 주석 오버레이도 — 캡처에 그대로 담깁니다.

영역 캡처 → 텍스트온디바이스 처리그리기 오버레이

창 스냅

다른 앱 창을 좌/우 절반·최대화·가운데로 정렬. 전역 단축키 ⌃⌥ + 방향키로 어디서든 — Windows의 창 스냅을 맥에서 그대로.

⌃⌥←⌃⌥→⌃⌥↑ 최대화⌃⌥↓ 가운데

클립보드 히스토리

복사한 텍스트 50개·이미지 10개를 검색하고 클릭 한 번으로 재복사. 메모리에만 보관하고 비밀번호 복사는 수집하지 않습니다.

도구상자

Finder·Dock 재시작, DNS 플러시, Spotlight 재색인 등 맥 응급처치 + 숨김파일·확장자 등 숨은 설정 토글 + 포트 점검·종료.

숨겨진 돈 찾기

휴면예금·보험금·카드포인트·미환급금 — 정부·공식기관 조회처만 모았습니다. 개인정보는 입력받지 않습니다.

보안 · 프라이버시

정직한 보안.
가짜 경고는 없습니다.

macOS 내장 보안 시스템의 실제 상태를 조회해 그대로 보여줍니다. 공포 마케팅으로 결제를 유도하는 "가짜 백신"과는 다릅니다.

보안 상태 점검

XProtect 버전, SIP, Gatekeeper, FileVault, 방화벽, OS 업데이트, hosts 변조, 구성 프로파일까지 — 시스템의 실제 값을 읽어 9개 항목을 점검합니다.

멀웨어 정밀검사

임시 경로·숨김 폴더에서 자동 실행되는 항목, 서명이 깨진 실행 파일, 애드웨어 상주 흔적을 휴리스틱으로 탐지하고 휴지통 격리합니다.

개인정보 관리

가입 사이트 정리, 털린 내 정보 조회, 명의도용 방지 — 검증된 정부·공식기관 서비스 바로가기만 제공합니다. 앱은 개인정보를 저장하지 않습니다.

홈

메모리·디스크 링 게이지(실시간), 배터리·가동시간, 스마트 정리 + 부스트

스마트 점검

메모리·디스크·캐시·휴지통·시작 프로그램 종합 건강 점검 + 원클릭 이동

모니터

CPU 코어별·GPU·메모리 분해·디스크·네트워크 실시간 대시보드

배터리 & 기기

배터리 건강 실측 + 충전 습관 24시간 리포트 + 블루투스 기기 배터리·부족 알림

네트워크

앱별 트래픽 + 인터넷 속도 실측 + Wi-Fi 신호 진단 + 채널 혼잡도 스캔·추천

딥 클린

브라우저·개발도구·Xcode·임시·진단 캐시 심층 정리 + 오래된 다운로드

중복 파일

SHA-256 해시 기반 중복 스캔 — ★ 첫 파일만 남기고 일괄 정리

앱 정리

설치 앱 검색·정렬, 삭제 시 잔여물(설정·캐시)까지 동반 제거

대용량 파일

100MB+ 파일 스캔, 타입 필터, Finder 열기·휴지통 이동

저장공간 탐색

폴더별 용량 트리맵 시각화 + 드릴다운·브레드크럼

폴더 정리

다운로드·데스크탑·임의 폴더를 이미지/문서/영상/압축별 자동 분류

압축

ZIP·TAR.GZ·BZ2·XZ 압축/해제, ZIP 암호 지원, 내용 미리보기

디스크 정리

모든 정리 소스를 도넛 차트로 모아 종합 원클릭 정리

프로세스

메모리/CPU 상위 프로세스 실시간 조회·검색·안전 종료

시작 프로그램

LaunchAgents 자동 실행 항목 조회·끄기 — 언제든 복구 가능

보안

SIP·Gatekeeper·FileVault·방화벽 등 9항목 점검 + 멀웨어 정밀검사

시스템 정보

칩·코어·메모리·시리얼·디스크 SMART 등 하드웨어 상세

숨겨진 돈 찾기

휴면예금·보험금·카드포인트·미환급금 정부 공식 조회처 모음

스크린샷

전체/영역/창 캡처 + OCR 텍스트 추출(한·영) + 화면 그리기 주석

클립보드

복사 히스토리 검색·재복사 — 메모리만 보관, 비밀번호 수집 제외

도구상자

맥 응급처치 + 숨은 설정 토글 + 포트 점검·종료

창 스냅

좌/우 절반·최대화·가운데 정렬 — 전역 단축키 ⌃⌥+방향키

개인정보 관리

가입 사이트 정리·털린 내 정보 등 공식기관 서비스 바로가기

설정

알림·메뉴바·자동 정리 예약·로그인 시 자동 실행

안전 원칙

빠르게 정리하되,
잃어버리지 않게.

원칙 01

삭제 전 반드시 확인

부스트·휴지통 비우기·파일 삭제·프로세스 종료 — 모든 파괴적 작업은 확인 다이얼로그를 거칩니다.

원칙 02

사용자 영역만

캐시·로그 정리는 ~/Library 안에서만. 시스템 영역은 절대 건드리지 않습니다.

원칙 03

휴지통으로 이동

파일 삭제는 영구 삭제가 아니라 휴지통 이동 — 언제든 되돌릴 수 있습니다.

원칙 04

사용 중 파일 보호

앱이 쓰고 있는(잠긴) 캐시는 자동으로 건너뜁니다. 작업을 방해하지 않습니다.
