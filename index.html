모니터

CPU 코어별 부하, GPU 사용률, 메모리 분해(활성·고정·압축), 디스크, 네트워크 스파크라인을 한 화면에서 봅니다.

배터리 & 기기

사이클·풀충전 용량·온도·전압·어댑터 와트를 실측합니다. 24시간 충전 습관 차트와 에어팟·마우스·키보드 배터리도 함께.

Wi-Fi 진단

신호(RSSI)·노이즈·SNR·연결 속도·채널을 실측하고, 주변 채널 혼잡도를 스캔해 한산한 채널을 추천합니다.

인터넷 속도 측정

핑·다운로드·업로드를 공개 측정 서버로 실측합니다. 앱별 트래픽 사용량도 함께 봅니다.

스마트 점검

메모리·디스크·캐시·휴지통·시작 프로그램을 종합 점검하고, 문제 항목으로 바로 이동합니다.

정리는 되돌릴 수
있어야 합니다

캐시·로그·휴지통·중복 파일·앱 잔여물까지. 모든 정리는 사용자 영역만 건드리고, 삭제 대신 휴지통으로 이동합니다.

부스트

사용자 캐시·로그·휴지통을 한 번에 정리합니다. 일·주·월 단위 백그라운드 자동 정리 예약도 지원합니다.

딥 클린

브라우저·개발 도구·Xcode·임시·진단 캐시를 카테고리별로 심층 정리하고, 오래된 다운로드도 찾아냅니다.

중복 파일

SHA-256 해시로 내용이 똑같은 파일을 찾아 한 개만 남기고 정리합니다. 부분 해시로 거른 뒤 전체 해시로 재검증하고, 비슷한 사진(dHash)도 찾아냅니다.

앱 정리

앱을 지워도 남는 잔여물(설정·캐시·지원 파일)까지 함께 제거합니다.

대용량 파일

100MB 이상 파일을 타입별로 스캔해 Finder에서 열거나 휴지통으로 보냅니다.

저장공간 탐색

폴더별 용량을 트리맵으로 시각화하고 드릴다운합니다. 어디가 무거운지 한눈에 보입니다.

폴더 정리 + 압축

다운로드·데스크탑을 이미지·문서·영상별로 자동 분류합니다. 정리 직후 되돌리기도 지원합니다. ZIP·TAR.GZ 압축과 해제(암호 지원)까지.

매일 쓰게 되는 도구들

스크린샷 OCR, 클립보드 히스토리, 창 스냅, 맥 응급처치. 하루에도 몇 번씩 쓰는 도구들을 담았습니다.

스크린샷 + OCR

전체·영역·창 캡처(PNG·JPG·PDF)에 더해, 화면 속 글자를 온디바이스 Vision으로 추출합니다(한·영). 화면 속 QR코드도 바로 인식합니다. 펜·화살표·도형 주석 오버레이도 캡처에 그대로 담깁니다.

창 스냅

다른 앱 창을 좌/우 절반·최대화·가운데로 정렬합니다. 전역 단축키 ⌃⌥ + 방향키로 어디서든.

클립보드 히스토리

복사한 텍스트 50개·이미지 10개를 검색하고 클릭 한 번으로 재복사합니다. 메모리에만 보관하고 비밀번호 복사는 수집하지 않습니다.

도구상자

Finder·Dock 재시작, DNS 플러시, Spotlight 재색인 같은 맥 응급처치와 숨은 설정 토글, 포트 점검·종료를 모았습니다.

정직한 보안

macOS 내장 보안 시스템의 실제 상태를 조회해 그대로 보여줍니다. 공포 마케팅으로 결제를 유도하지 않습니다.

보안 상태 점검

시스템의 실제 값을 읽어 9개 항목을 점검합니다.

멀웨어 정밀검사

임시 경로·숨김 폴더의 자동 실행 항목, 깨진 서명, 애드웨어 흔적을 휴리스틱으로 탐지하고 격리 보관함으로 옮깁니다. 원위치 기록과 함께 보관해 언제든 복원할 수 있고, 브라우저 확장 점검(조회·경고만)도 함께 제공합니다.

점검 항목
XProtect 버전 SIP Gatekeeper FileVault 방화벽 OS 업데이트 hosts 변조 구성 프로파일 자동 실행 항목

전부 시스템에 이미 있는 값을 조회하는 방식입니다. 앱이 별도 백신 엔진을 설치하지 않습니다.

한국 사용자를 위한
다섯 가지

개인정보는 입력받지 않고, 검증된 공식 조회처와 본인 기기 안에서만 동작합니다.

서버에 절대 보내지 않는 가계부

카드사·은행 명세서 CSV를 드래그하면 자동 분류되고, 월별 리포트로 봅니다. 내역은 이 컴퓨터의 로컬 파일에만 저장됩니다. 데이터는 이 컴퓨터를 떠나지 않습니다.

숨겨진 돈 찾기

휴면예금·보험금·카드포인트·미환급금. 정부·공식기관 조회처 9곳만 모았습니다. 개인정보는 입력받지 않습니다.

NPKI 인증서 정리

쌓인 공동인증서를 100% 온디바이스로 파싱해 만료 여부를 확인하고 정리합니다. 인증서 정보는 기기 밖으로 전송하지 않습니다.

개인정보 관리

가입 사이트 정리, 털린 내 정보 조회, 명의도용 방지. 검증된 정부·공식기관 서비스 바로가기만 제공하고, 앱은 개인정보를 저장하지 않습니다.

포렌식

사진 진위·기기 무결성·봉인 리포트를 확인합니다. 본인 기기에서만 동작합니다.
