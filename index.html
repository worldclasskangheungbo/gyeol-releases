사용하기 전에 알아두세요.

내 데이터는 어디에 보관되나요?

가계부·설정·작업 이력은 Mac에 저장되며, 개인 파일은 로컬에서 처리합니다. 클립보드 기록은 메모리에 보관합니다. 비밀번호 관리자의 보호 표시를 참고하지만 모든 비밀번호를 자동 판별할 수는 없습니다.

외부에는 언제 연결되나요?

업데이트 확인은 GitHub, 속도 측정은 Cloudflare에 연결합니다. 제휴 상품 피드를 받을 수 있으며, 외부 링크를 열면 해당 사이트의 정책이 적용됩니다.

정리하기 전, 무엇을 확인해야 하나요?

선택한 대상과 용량을 확인하고, 해당 파일을 사용하는 앱을 종료해 주세요. 휴지통으로 옮긴 파일은 비우기 전까지 복원할 수 있습니다. 휴지통 비우기는 영구 삭제이며, 실제 공간 확보는 이 단계에서 이루어집니다.

어떤 권한이 필요한가요?

선택한 기능에 따라 폴더 접근·화면 기록·손쉬운 사용 권한이 필요합니다. 보안 점검은 진단을 돕는 기능이며 위협이 없음을 보증하지 않습니다. ClamAV 검사는 별도 설치가 필요합니다.

무료인가요? 광고가 있나요?

도구는 무료로 제공하며 일부 화면에 제휴 광고가 포함됩니다. 제휴 링크를 통한 구매 시 수수료를 받을 수 있습니다. GYEOL은 Apple의 제품이나 공식 제휴 서비스가 아닙니다.

공개 ZIP에 .NET 8 런타임이 포함되어 별도로 설치할 필요가 없습니다. 설치 마법사가 없는 x64 포터블 앱입니다. ‘모두 압축 풀기’ 후 GYEOL 폴더의 GYEOL.exe를 실행하고, 함께 있는 DLL·JSON 파일을 유지하세요. 파일 무결성과 런타임 구성은 확인했으며 Windows 기기에서의 실행 검증은 남아 있습니다. 베타 실행 파일에 배포자 서명이 없어 Windows가 차단할 수도 있습니다.

Android · APK가 설치되지 않을 때

Android 8 이상에서 직접 설치하는 v0.7 베타 APK입니다. 다운로드에 사용한 브라우저·파일 앱의 설치 권한과 기기의 보안 안내를 확인하세요. 기존 앱과 서명키가 다르면 업데이트가 막힐 수 있습니다. 기존 앱과 데이터를 지우지 말고, 먼저 오류 문구·기기 모델·Android 버전을 알려주세요. 파일 검사는 통과했지만 기기별 설치는 확인이 필요합니다.
